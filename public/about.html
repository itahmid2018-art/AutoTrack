Modular Workshop Capabilities

Every feature is designed specifically for high-throughput industrial repair centers.

01

Advanced Tool Intake & Warranty Adjudication

Captures tool serial numbers, brand models, physical condition notes, and automatically adjudicates warranty status using factory date codes and purchase references.

02

Kanban Repair Stage Pipeline

Interactive drag-and-drop workflow tracking jobs from Intake through Diagnostics, Parts Waiting, Repair in Progress, Quality Control, and Ready for Dispatch.

03

1,000-SKU Spare Parts Catalog & Auto-Deduction

Maintains inventory levels with automatic stock deductions upon stage transitions, low-stock notifications, and intelligent parts suggestions matching job tool brands.

04

QR Code Payloads & Role-Based Global Scanners

Generates scannable QR tags embedding secure tokens and job IDs. The global scanner enforces role boundaries: clients get view-only access to their specific job, while admins receive full operational control.

{/* TAB 2: ARCHITECTURE */}

How the Code Works

Built with a robust, type-safe full-stack architecture ensuring reliability under intermittent workshop network connectivity.

Frontend Stack
  • • React 19 + TypeScript (Strict)
  • • Vite 8 Build System & HMR
  • • Tailwind CSS v4 Utility Styling
  • • LocalStorage TransactionalDb Cache
Backend & Persistence
  • • Node 22 + Express 4 Middleware
  • • Cloud Firestore Realtime Sync
  • • PostgreSQL 16 via Drizzle ORM
  • • Service Worker PWA Offline Store
Security & Auth
  • • Firebase Auth & Google Workspace SSO
  • • Server-side JWT Verification
  • • Role-Based Access Control (RBAC)
  • • Tokenized Client Portal URL Lookup

Data Lifecycle & State Management

State changes are funneled through transactional utility layers (`stockDeduction.ts`, `billing.ts`, `firestoreSync.ts`). When offline, mutations are buffered in local storage queue and automatically synced to Firestore upon reconnection, avoiding data loss in concrete-walled workshops.

User Distribution & Usage Patterns

Understanding how different personas interact with AutoTrack Pro across daily service operations.

Workshop Technicians

55% Usage

Primary users for diagnostic check-ins, barcode scanning, part allocations from inventory, time tracking, and updating Kanban repair stages.

Service Managers

20% Usage

Monitor workshop KPIs, revenue forecasts, staff allocation, scheduling calendars, and review turnaround times by tool category.

Inventory Supervisors

15% Usage

Manage spare parts catalog across 1,000 SKUs, review low-stock alerts, execute bulk CSV imports, and process quick reorders.

End-Client Customers

10% Usage

Access isolated Client Status Portal via tokenized URLs or QR codes to view repair progress, download invoice receipts, and submit feedback.
